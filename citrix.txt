Xen
Xen is a Type 1 (bare-metal) hypervisor that enables the execution of
multiple virtual machines (VMs) on a single physical machine by abstracting the
hardware. It supports both paravirtualization and hardware-assisted full
virtualization (via Intel VT or AMD-V).

Requirements for Live Migration in Xen
Shared Storage (e.g., NFS, iSCSI, SAN): Both hosts must access the same
virtual disk. Same CPU family: Compatible CPU features between source and
destination.  Network Connectivity: Low-latency, high-speed network between hosts. Xen-compatible tools: xm, xl, or XenAPI-based management like
XenCenter.  Proper Configuration: Dom0 should have migration tools enabled, with
firewall ports open.

1a)
Citrix XenServer is a virtualization platform based on the open-source Xen
Hypervisor. It enables efficient creation, management, and execution of multiple
virtual machines (VMs) on a single physical host.
Installation Steps:
1. Download ISO:
o Get the official XenServer ISO from Citrix website.
2. Create Bootable Media:
o Use tools like Rufus or Ventoy to create a bootable USB with
XenServer ISO.
3. BIOS Settings:
o Enable VT-x / AMD-V (hardware virtualization) and set USB as first
boot device.
4. Boot and Install:
o Insert the USB and boot the server.
o Follow the on-screen instructions:  Select installation drive (e.g., local disk).  Configure network settings (static IP recommended).  Set root password.  Choose to install XenServer tools
5. Complete Installation:
o Reboot system after installation.
o XenServer boots with a console UI showing IP address and system
info.
